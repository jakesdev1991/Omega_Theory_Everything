\section*{Layman's Summary}
Game theory studies strategic interactions between decision-makers. The prisoner's dilemma is its standard example, in which individually rational choices lead to a worse outcome for both players. This volume records that example with stipulated payoffs. It is not a derivation of economic or social behavior from physics.

\section{Dominant Strategy (Formal Result within the Model)}
With the stipulated payoffs, defection strictly dominates cooperation for each player. This is a finite check.

\section{Nash Equilibrium (Formal Result within the Model)}
Mutual defection is the unique pure Nash equilibrium of the stipulated game. The file establishes this by checking every unilateral deviation.

\section{Pareto Dominance (Formal Result within the Model)}
Mutual cooperation yields both players a higher payoff than mutual defection. The file records this.

\section{Multi-Agent Equilibria from Modular Flow (Not Formalized)}
The earlier claim that interacting agents converge to Nash equilibria because of modular flow is not formalized. It is withdrawn as a claim of this work and is listed as an open item.

\section{Evolution of Cooperation (No Formal Counterpart)}
The earlier claim that cooperation is a mathematical guarantee in repeated games has no formal counterpart. The file contains no repeated game. The claim about Tit-for-Tat is withdrawn.

\section{Tragedy of the Commons (No Formal Counterpart)}
The earlier claim that local optimization leads to global topological collapse has no formal counterpart. It is withdrawn.

\section{Scope and Open Items}
