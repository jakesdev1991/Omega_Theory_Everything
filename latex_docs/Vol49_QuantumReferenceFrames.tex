\section*{Layman's Summary}
Quantum reference frames study how the description of a system depends on the reference frame of the observer. This is an active research area with several competing formulations. This volume records a one-dimensional phase model, which captures only the simplest case of frame change. It does not settle the interpretive questions.

\section{Phase Frames (Formal Result within the Model)}
Frames are unit-norm phases, and a change of frame multiplies by the ratio of phases. The file establishes composition, identity, round-trip, and norm preservation for these maps.

\section{Relational Quantum Mechanics (Interpretation, Not Formalized)}
The earlier claim that quantum states only have properties relative to observer nodes is an interpretation. The file does not formalize relational quantum mechanics. It is withdrawn as a claim of this work.

\section{Wigner's Friend (No Formal Counterpart)}
The earlier claim that both the friend's and the outside observer's descriptions are right, and that no contradiction arises, has no formal counterpart. It is withdrawn and is listed as an open item.

\section{Gauge Invariance of Reality (No Formal Counterpart)}
The earlier claim that objective reality is the gauge-invariant intersection of all reference frames has no formal counterpart. It is withdrawn.

\section{Scope and Open Items}
\begin{itemize}
  \item Not established here: relational observers; general quantum reference frames; Wigner's friend; objectivity of physical reality.
\end{itemize}
