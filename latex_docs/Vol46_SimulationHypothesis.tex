\section*{Layman's Summary}
The simulation hypothesis proposes that our reality is a computation run inside another reality. It is a philosophical hypothesis, not an established scientific result. This volume records the logical structure of nested layers. It does not test or support the hypothesis.

\section{Simulation Layers (Formal Result within the Model)}
Simulation layers form a strict tower, the base layer is not simulated, and the simulation relation is reflexive and transitive. These are facts about the tower as defined in the file.

\section{Computational Equivalence (Not Formalized)}
The earlier claim that a perfect simulation is mathematically identical to base reality is an interpretive claim. The file does not compare physical reality with computation. It is withdrawn as a claim of this work.

\section{Simulation Resolution Bound (No Formal Counterpart)}
The earlier claim that an embedded simulation must have a lower resolution than its host has no formal counterpart. It is withdrawn.

\section{Glitches and Anomalies (No Formal Counterpart)}
The earlier claim that truncation errors would appear as high-energy anomalies in cosmic rays is a speculative prediction, not a result of this volume. It is withdrawn. It is not tested here.
