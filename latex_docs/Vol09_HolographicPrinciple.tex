\section*{Layman's Summary}
The holographic principle proposes that the information needed to describe a region of space can be encoded on its boundary. This volume gives a small, explicit model of that idea. It is a dictionary between a toy anti-de Sitter (AdS) bulk and a boundary theory, together with an exact statement about two qubits. It is a mathematical model, not an observation about our universe.

\section{Holographic Dictionary (Model Assumption 12)}
The dictionary between bulk fields and boundary data is taken as a model assumption. The formal file encodes it as a map from the AdS parameterization to boundary fields. The file does not derive this dictionary from a microscopic theory.

\section{Bulk Reconstruction (Definitional in the Model)}
Within the model, bulk fields are identified with the boundary fields they are mapped to. The corresponding Lean statement holds by definition. It is a bookkeeping identity of the model, not a reconstruction theorem about physical bulk geometry.

\section{Ryu--Takayanagi Relation (Model Claim)}
The Ryu--Takayanagi relation between boundary entanglement entropy and minimal bulk surface area is stated in the formal file as a model claim. The file's own header records that it is definitional within the model. It is not derived from a variational principle or from the Einstein equations.

\section{Two-Qubit EPR/ER Criterion (Formal Result within the Model)}
For a two-qubit pure or mixed state described by a correlation matrix, the formal file shows that the state is a product state if and only if its correlation determinant is zero. Equivalently, the state is entangled if and only if that determinant is nonzero. This is a finite algebraic statement about two qubits. It does not show that entanglement generates geometry in general, and it does not extend to multi-qubit or continuum systems.
