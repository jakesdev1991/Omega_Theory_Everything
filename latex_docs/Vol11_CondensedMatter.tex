\section*{Layman's Summary}
Some materials show quantized electrical responses, and some conduct with zero resistance. This volume records two formal models: a Landau free-energy minimization, and a Chern-band model with an integer invariant. Neither model is derived from the Omega framework, and neither is a theory of superconductivity.

\section{Landau Phase Transition (Formal Result within the Model)}
For a quartic Landau free energy with positive quartic coefficient, the formal file characterizes the minimizers and shows how the order parameter changes at the critical point. This is standard Landau theory for the chosen polynomial. It does not establish the microscopic origin of the coefficients.

\section{Topological Band and Hall Response (Formal Result within the Model)}
The formal file defines a \texttt{ChernBand} as a structure whose Chern index is an integer field. The quantization theorem (\texttt{chern\_number\_quantized}) therefore holds by construction: integrality is built into the definition, not derived from Berry curvature (\texttt{BerryCurvature} is defined as the constant $0$ in the file). The file also computes the Hall response of the specific Haldane-type model band. The file does not show that physical materials realize this band structure, and it does not derive the band from the modular flow. The quantized Hall response described in earlier text is therefore a property of the model only.

\section{Legacy Zero-Chern Model}
Earlier stubs with zero Chern number are retained and labeled legacy in the source. They are not used as evidence for any physical claim.

\section{Superconductivity (No Formal Counterpart)}
The earlier description of superconductivity as a localized freezing of informational flow has no corresponding formal statement in this volume. It is withdrawn as a claim of this work and is listed as an open item.
