\section*{Layman's Summary}
Quantum gravity aims to combine quantum mechanics and general relativity. This volume records formal constraints and models that appear in quantum gravity approaches. It does not contain a complete quantum theory of gravity, and it does not resolve singularities.

\section{Wheeler--DeWitt Balance (Formal Result under Stated Assumptions)}
For a Wheeler--DeWitt-type constraint $H_m + H_g$ annihilating a state, the formal file shows that the expected matter and gravity energies have opposite signs. The result depends on the stated operator assumptions. It is not a derivation of the constraint from a microscopic theory.

\section{Mini-Superspace Model (Formal Result within the Model)}
In the mini-superspace model the file shows that the constraint can be satisfied, and that satisfaction is not automatic. This is a finite model, not a general solution of quantum gravity.

\section{Area Gap (Formal Result within the Model)}
For a spin-network model with positive parameters, the file shows that the smallest nonzero area is positive. This is a statement about the model's area spectrum. It is not a measured prediction.

\section{Graviton Helicity (Formal Result within the Model)}
Two graviton helicity states are shown to be distinct in the model. This is a finite distinctness statement.

\section{Graviton--Standard Model Coupling (Trivial in the Model)}
The formal statement that a graviton couples to the Standard Model gauge group holds because the self-distance of a region is zero. This is not a coupling in the physical sense, and it should not be cited as evidence of one. The earlier claim is withdrawn.

\section{Singularity Resolution (No Formal Counterpart)}
The earlier claim that the framework resolves singularities has no formal counterpart in this volume. It is withdrawn as a claim of this work and is listed as an open item.
