\section*{Layman's Summary}
Artificial general intelligence refers to systems that perform well across a broad range of tasks. There is no agreed formal definition, and this volume uses a deliberately simple one. The model is a bookkeeping device for capability and demand. It does not describe any actual AI system or predict its trajectory.

\section{General Intelligence (Definition in the Model)}
In the model, an agent is general against a demand profile if its capability is at least the demand on every task. This is a definition, and the file does not argue that it captures intelligence.

\section{Closure Under Weaker Demand (Formal Result within the Model)}
If an agent is general against a demand, it is general against any weaker demand. This is immediate from the definition.

\section{No Vanishing Agent Is General (Formal Result within the Model)}
An agent with a vanishing capability profile cannot be general against a positive demand. This is a finite check.

\section{The Singularity (No Formal Counterpart)}
The earlier claim that recursive self-improvement produces a hyperbolic divergence in processing power has no formal counterpart. The model has no dynamics for self-improvement. It is withdrawn as a claim of this work.

\section{The Alignment Problem and Orthogonality (No Formal Counterpart)}
The earlier claim that the orthogonality thesis is proved has no formal counterpart. The file contains no goals, values, or optimization. It is withdrawn and is listed as an open item.
