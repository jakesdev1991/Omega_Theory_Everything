\section*{Layman's Summary}
Max Tegmark's Mathematical Universe hypothesis proposes that all mathematical structures exist as physical universes. It is a speculative proposal, and it is not established. This volume records a formal limitation on enumerating the structures that a formal system can name. It does not confirm the hypothesis.

\section{The Ensemble of Nameable Structures (Formal Result within the Model)}
In the file, a member of the ensemble is a structure together with a proof that it is inhabited. The ensemble is therefore the set of structures representable inside the formal system. The file proves that this ensemble is not enumerable by the system.

\section{Mathematical Existence (Interpretation, Not Formalized)}
The earlier claim that mathematical existence implies physical existence is the Mathematical Universe hypothesis. It is not formalized, and it is withdrawn as a claim of this work.

\section{Tegmark Level IV (No Formal Counterpart)}
The earlier claim that a Level IV multiverse exists is not formalized. It is withdrawn and is listed as an open item.

\section{Anthropic Selection (No Formal Counterpart)}
The earlier claim that observers can only find themselves in the structures that allow life has no formal counterpart. It is withdrawn.

\section{Scope and Open Items}
\begin{itemize}
  \item Not established here: the set of all mathematical structures; physical existence of mathematical structures; the multiverse; anthropic selection.
