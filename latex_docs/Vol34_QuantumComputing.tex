\section*{Layman's Summary}
Quantum computers process information using quantum gates, which are unitary transformations on qubits. This volume records the basic algebra of a few standard gates. It is a check of textbook facts about these gates. It is not a demonstration of quantum advantage.

\section{Gate Algebra (Formal Result within the Model)}
The two-element gate fragment forms a finite algebra in which $H$ is self-adjoint and involutive. Composition is associative and every gate has an inverse. These are finite checks.

\section{Explicit Gate Matrices (Formal Result within the Model)}
The file defines $H$, $X$, and $Z$ as $2 \times 2$ matrices and verifies that they are unitary. It also verifies that Hadamard conjugates $X$ to $Z$, that $X$ and $Z$ do not commute, and that $H$ preserves the norm of a qubit vector. These are standard identities.

\section{Quantum Supremacy (No Formal Counterpart)}
The earlier claim that quantum computers exploit an exponential computational capacity of the universe's algebra has no formal counterpart. The file contains no complexity analysis. It is withdrawn as a claim of this work and is listed as an open item.

\section{Shor's Algorithm (No Formal Counterpart)}
The earlier claim that Shor's algorithm works because it exploits a hidden modular flow of the universe has no formal counterpart. The file does not implement or analyze period finding. It is withdrawn.

\section{Topological Error Correction (No Formal Counterpart)}
The earlier claim that the only route to stable quantum computation is topological error correction has no formal counterpart. It is withdrawn.
