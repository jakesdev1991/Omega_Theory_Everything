# Plain Text Proofs - Omega Theory

This directory contains plain text versions of all Lean 4 proofs and LaTeX documents for accessibility, searchability, and archival purposes.

## Structure

- `Vol01_ClassicalMechanics.txt` through `Vol54_TheoryOfNothing.txt` - Text versions of Lean proofs
- `Vol09_HolographicPrinciple.txt` through `Vol54_TheoryOfNothing.txt` - Text versions of LaTeX docs

## Purpose

- Human-readable without Lean/LaTeX tooling
- Searchable with standard tools (grep, rg)
- Version control friendly (diffable)
- Accessible for screen readers
- Archival format independent of tooling

## Companion Files

- **Lean 4 proofs**: `../lean_proofs/` - Formal verification source
- **LaTeX docs**: `../latex_docs/` - Mathematical typesetting
